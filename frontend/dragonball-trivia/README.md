# Dragon Ball Trivia (MERN)

A simple Dragon Ball–themed trivia game built with the **MERN** stack (MongoDB, Express, React, Node).

Players answer multiple-choice questions about Dragon Ball, see their score at the end, and can save it to a leaderboard.

---

## Features

-  Multiple-choice Dragon Ball trivia quiz  
-  Questions are pulled randomly from MongoDB  
-  Score tracking at the end of each quiz  
-  Leaderboard that shows the top scores  
-  Dragon Ball–themed UI (Kame House background, Dragon Ball icon)

---

## Tech Stack

- **Frontend:** React (Vite)
- **Backend:** Node.js, Express
- **Database:** MongoDB Atlas (via Mongoose)
